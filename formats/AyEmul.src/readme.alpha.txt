Ay_Emul v3.0 alpha 11
3 of August 2004

Now you can use Ay_Emul v3.0 for playing modules instead of Ay_Emul 2.xx
versions.

For the moment Ay_Emul v3.0 is a light version of Ay_Emul 2.8 beta 4.
This alpha can play modules only, i.e. you can not convert and rip music, can
not adjust playing and emulation parameters (including playlist items).

But Ay_Emul v3.0 is a stable version, especially in WinNT and WinXP.
This alpha uses threads carefully, so, I hope, you can never see typical Ay_Emul
v2.x error messages in Windows XP (especially with many items in playlist).


By default, Ay_Emul v3.0 alpha 11 uses next settings:
Chip - YM
Chans - ABC
Sound - 16 bit, 44100, Stereo via WaveMapper
Emulation - high quality with FIR-filter
Priority - normal for WinNT/XP, high for Win9x/Me

If you want to use Ay_Emul v3.0 alpha 11 with other parameters (as you are
using in Ay_Emul v2.x), edit registry manually (at your own risk):

HKEY_CURRENT_USER\SOFTWARE\Sergey Vladimirovich Bulba\ZX Spectrum Sound Chip Emulator\3.0 alpha
